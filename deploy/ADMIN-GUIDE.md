# 独立网站使用说明

网站：https://capone-private-studio.capone-studio-136.workers.dev

后台：https://capone-private-studio.capone-studio-136.workers.dev/admin

## 第一次登录

账号为 `capone`，初始密码通过本地私密文件单独交付，不在公开仓库中。
首次登录按提示修改密码，最低5位，建议使用更长且不重复的密码。
这是新站的独立账号，不会修改旧网站账号。

## 接收与回复咨询

进入“咨询收件箱”查看留言，点击会话后可回复、标记已读或归档。
客户在咨询窗口打开时自动获取新回复；新会话的首次留言会收到一次固定自动回复。
客户无需注册，同一浏览器可继续会话，换设备或清除浏览器数据不会自动恢复匿名记录。

## 发布团队动态

在动态管理中上传图片或视频，填写标题和说明，可以先保存草稿，再发布。
每条动态对应一个媒体文件，只接受16:9或9:16比例。
图片上限10 MB，视频上限50 MB；客户不能上传或发布。
每条公开动态下方的私信入口会将来源带入咨询。

## 更换首页视频

进入“首页视频”，选择16:9或9:16的H.264 MP4，原片不超过50 MB。
保持页面打开，等待处理、上传和服务器检查完成；预览确认后点击“确认替换”。
取消或失败时原首页保持不变。原片私密保存，播放版本与封面在确认后公开。
首页默认静音循环，访客点击声音开关可听原声，暂停按钮独立控制播放。
建议使用支持视频编码的最新版桌面 Chrome 或 Edge 完成视频处理。

## 数据与访问

旧站的咨询记录、账号、后续上传动态和私密素材未迁移，仍保留在旧站。
新站从本次初始化后独立保存数据，两站不会自动同步。
请先测试客户所在地区的实际网络。当前默认域名不保证国内无需VPN即可访问。
R2按账号套餐和实际用量计费，请在Cloudflare后台关注用量与账单。
