# 卡彭团队 · 女性吸睛私人定制

公开品牌网站、免注册私密咨询，以及单管理员图文视频后台。

## 日常使用

- 网站首页展示团队介绍、服务流程、承接边界与已发布动态。
- 管理入口为网站地址后的 `/admin`。管理员账号为 `capone`；初始密码仅在本地 `.private/管理员登录.txt` 中提供，首次登录必须修改。
- 修改密码最低5位、最长128位，建议使用更长且不重复的密码。更新网站不会重置已经修改的密码。
- 「首页视频」可上传50 MB以内的H.264 MP4，限16:9或9:16。浏览器自动优化、生成封面后可预览，点击「确认替换」才会上线；取消或处理失败保留原首页。请使用支持H.264 WebCodecs编码的新版Chrome或Edge。
- 首页原文件私密保存；公开播放版最高960像素长边、30帧、约1 Mbps，保留完整画面、字幕和AAC原声。首页静音自动播放，点击声音图标开启原声。进入咨询会停止并移除背景视频，关闭后静音恢复；此前手动暂停的保持暂停。
- 选择视频后，原片私密上传与处理并行，最多两路上传。各文件显示实际上传容量及检查状态；确认替换前不会公开。合规视频直接快速封装，不重复压缩。失败时可「重试未完成步骤」，已成功上传的文件不会重复传输；取消后旧首页保持不变。
- 已更换过视频但旧播放版无声时，使用「从已保存原片恢复声音」，预览并确认替换，无需重新上传原片。原片本身无声会明确提示；无法保留原声的浏览器不会发布一个无声替代品。
- 咨询收件箱支持查看、回复、归档和删除；客户端无需注册，在同一浏览器内继续会话。
- 团队动态支持草稿、发布、编辑、撤下与删除。每条帖子包含一张图片或一段视频，画幅限16:9或9:16。
- 图片支持 JPG、PNG、WebP，最大10 MB；视频支持 H.264 MP4，最大50 MB。
- 语音沟通与私人交付通过官方微信或 WhatsApp 承接，本站不提供付款与客户附件上传。

## 数据与权限

Sites 托管应用；D1 保存会话、消息、帖子和登录状态；R2 保存上传媒体。匿名会话使用 HttpOnly Cookie 隔离。管理接口逐次核验唯一管理员身份；未发布媒体不可匿名读取。

初始化接口仅接受部署密钥，并在管理员创建后关闭。公开注册与非必要账号接口均禁用。登录与留言具有限流和请求来源检查。

首页配置保存在独立的 `homepage_settings` 表；`0001_premium_gorgon.sql` 仅新增该表及媒体用途、时长和帧率字段，不修改已有账号、消息或帖子。未设置首页视频时使用内置的优化版本。媒体删除先检查引用，数据库外键也会保护正在使用的文件。

`0002_flimsy_wasp.sql` 增量添加音轨标记及上传任务、任务素材表。`POST /api/admin/homepage/tasks` 创建私密任务，`GET/DELETE /api/admin/homepage/tasks/:id` 查询或取消，素材上传关联 `taskId`，`PATCH /api/admin/homepage` 完成原子确认。任务24小时过期，后续首页管理请求清理未引用素材；已确认发布的素材不会被取消任务删除。不支持跨设备续传。上传租约防止重复请求覆盖正在处理的文件，丢失响应通过任务状态核对。

首页采用服务端内容与按需交互组件；动态接近视口才加载，非首屏视频不预取。可撤下媒体每次访问先核验权限，再处理ETag条件请求。咨询和管理接口保持no-store。静态资源的实际缓存效果还受托管平台策略影响。

`.private/`、`.dev.vars`、`.env`、本地数据库、测试结果和构建产物不进入源代码仓库。请勿公开管理员凭据或服务密钥。

## 本地开发

需要 Node.js 22.13+ 与 npm。

```sh
npm ci
node scripts/prepare-secrets.mjs
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_cute_morbius.sql
npm run dev
```

数据库迁移仅对尚未初始化的本地数据库执行一次。生产环境由 Sites 应用生成的迁移，并通过 Sites 配置 `.env.example` 中的运行变量。

既有本地数据库按顺序执行尚未应用的 `0001_premium_gorgon.sql` 和 `0002_flimsy_wasp.sql`，每份只执行一次；不要重复执行初始迁移。

`scripts/qa-upgrade.mjs` 仅在本地验证5位密码、首页视频优化与替换、取消、权限和多端布局，并恢复测试前的首页设置。`scripts/performance.mjs` 记录三次手机冷启动和重复访问，条件为10 Mbps、100 ms延迟、4倍CPU降速。

`scripts/qa-consult-video.mjs` 验证咨询期间移除视频、原声解码、暂停和位置恢复、上传任务取消/重试/过期、丢失响应与原声恢复。自动浏览器测试不能替代安卓厂商自带浏览器真机回测。

`scripts/qa-upload-performance.mjs before|after` 在本地以5 Mbps上传、10 Mbps下载和100 ms延迟配置比较串行旧流程与并行新流程，各测3轮小文件及接近50 MB的真实可播放文件。先在旧优化器源代码上运行before以保存旧实现，测试数据和报告仅存本地test-results目录。

`scripts/prepare-home-video.mjs` 使用与后台相同的浏览器优化逻辑生成初始轻量素材。未来重新生成内置素材时需要更换文件版本名，避免已有浏览器缓存旧版本。

`scripts/qa.mjs` 仅对本地预览运行，使用 Playwright 验证权限、消息、媒体与多端布局；测试结束会清理测试帖子、媒体与咨询。测试用的管理员新密码保存在本地 `.private/qa-password.json`，不影响生产环境初始凭据。

前台提供可选的 WebMCP 咨询窗口打开接口，浏览器不支持时正常忽略。测试浏览器不提供原生 WebMCP，因此未验证原生代理调用。
